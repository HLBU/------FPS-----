# 史上最反人类 FPS：机制与数值说明

本文由实际配表生成，修改 config/balance.csv 后重新构建会同步更新。Excel 主表为 config/游戏数值.xlsx，日常调整建议从 Excel 主表开始。

## 定位和当前范围

电脑浏览器键鼠、3D、小型竞技地图、真人 1V1 与单人人机。核心是部位伤害倒置、官方外挂与违反传统操作习惯的移动射击。双方采用同一把全自动步枪。本轮加入右键肩射和 V 短冲刺。尚未加入瞄准镜、护甲、多人队伍、经济系统和其他枪械。

## 对局流程

1. 人机模式直接开局；真人模式由一人创建房间，复制邀请链接，另一人打开链接并点击加入。
2. 网站已经开放链接访问，访客无需 ChatGPT 账号。房间码独立于网站访问权限。
3. 每回合从十个外挂中随机提供同样的三个；双方各暗选两个，允许选重。双方确认后进入 5 秒准备阶段，公开双方外挂与说明，禁止移动、跳跃和开火，倒计时结束后统一开战。
4. 外挂持续有效，没有周期触发；所有玩家另有一个带冷却的公共位移技能。每小局结束、开始下局时全部清空。
5. 先赢 3 小局获胜，通常最多 5 个有胜负的小局。平局重赛不计胜负。
6. 每小局 75 秒，一人生命归零即结束。最后 15 秒双方轮廓公开；超时比较剩余生命，同血量重赛。

## 操作

| 输入 | 功能 |
|---|---|
| WASD | 移动；斜向归一化，不会更快 |
| 鼠标滑动 | 直接转向，无需按住右键 |
| 左键 | 按住持续射击 |
| 右键 | 按住肩射：略微放大、减小散布并限制机动性 |
| 空格 | 跳跃；按住落地后连续跳跃。趴下时首次按下只尝试站起，松开后再按才跳 |
| Q / E | 按住向左 / 右探头；同时按下中和，松开回正 |
| R | 手动换弹；不会自动换弹 |
| Shift | 按住冲刺；仅站立姿态可冲刺且仍可射击 |
| Ctrl | 按住下蹲，松开尝试站起；上方受阻时保持蹲姿 |
| Z | 切换趴下和站立；上方受阻时不能站起 |
| V | 短距离水平冲刺：方向由 WASD 决定，无方向输入则向前；空中可用 |
| ESC | 暂停菜单并释放鼠标 |

默认使用浏览器鼠标锁定，支持无限转向。在不允许鼠标锁定的内置网页中，可用“窗口内自由视角”，同样直接滑动鼠标转向，但光标到窗口边缘时受限，推荐在独立 Chrome / Edge 中玩。方向键保留作为备用转向。人机暂停会停止模拟；真人对局菜单不会暂停另一名玩家。

## 基础战斗

- 全自动即时命中射击，最大射程 100 米，不使用飞行中的实体弹丸。
- 最大生命 400；头部 10、躯干 25、四肢 50 单发伤害，没有距离衰减。
- 站立散布最大，实际水平速度超过 1 米/秒时采用移动散布；不接地时采用腾空散布。散布数值是水平和俯仰各自的最大随机偏角，单位弧度。
- 子弹间隔 0.115 秒，约 521.7 发/分钟；24 发弹匣。无限子弹不消耗弹药。
- 空匣按 R 需 0.65 秒，非空匣按 R 需 1.75 秒；不会自动换弹。
- 向下开枪时立即保证至少 9 米/秒升速，后续射击增量为向下方向分量 × 6，向上速度封顶 14 米/秒，脚底最高 8 米。不会造成自伤。
- 自瞄在开火时工作，必须有直接视线，优先可见四肢，然后躯干和头。向下俯视超过约 63° 时优先保留射地操作，避免锁定阻碍起飞。自瞄只改变射击方向，不再拉回鼠标镜头；普通腾空和射地飞行均可自由转向。

## 探头的真实判定

Q 为左、E 为右。站立时围绕距离脚底 0.7 米的髋部支点倾斜上半身，下蹲和趴下使用相应的较低支点，最大 0.35 弧度（约 20.1°）。头、躯干、手臂与武器外观随之移动，腿保持原位。眼睛与射击起点跟随探头；敌人命中判定使用同样变换后的部位盒。探头接近墙体时会收缩，避免视点穿墙。第一人称有小幅画面倾斜，第三人称仍能探头。

## 十个官方外挂

| 外挂 | 当前规则 |
|---|---|
| 透视 | 持续显示敌人位置和墙后轮廓，显示其实际探头及缩小姿态 |
| 自瞄 | 开火时锁可见要害，手动开火，仍受散布影响；不能隔墙锁定 |
| 子弹穿墙 | 所有场景墙体均可穿，保持完整伤害，不附赠透视或隔墙锁定 |
| 没有脚步 | 取消自己的移动和落地声音，枪声保留 |
| 第三人称 | 右肩后置摄像机，肩射时拉近，碰墙时收回；准星视线向目标点收敛，仍从角色自身判定遮挡，不能用摄像机绕墙开枪 |
| 超级移速 | 不按 Shift 与普通玩家同速；按住 Shift 达基础速度 × 2.5（13 米/秒），不再叠乘普通冲刺 |
| 没有四肢 | 四肢不可见且不参与命中，头和躯干仍可受伤 |
| 无限子弹 | 弹匣不消耗，无需换弹，射速不变 |
| 自动回血 | 持续 100 点/秒，受击不中断，最多恢复到 400；死亡后不复活 |
| 人物缩小 | 模型、命中区域、移动碰撞和视点同步变为 70%，基础移速不变 |

## 地图与人机

地图为 32×40 米镜像训练场：中央核心障碍、两条侧翼、交叉连接、低掩体和底部露腿隔断。墙体阻挡移动、视线和自瞄，但不阻挡穿墙外挂。角色有水平边界限制，不可飞出地图。没有可破坏建筑或多层复杂室内空间。

机器人使用网格寻路，直接可见时追击射击，丢失视线时追踪最后位置；没有透视时不会无条件知道墙后坐标。它使用相同血量、伤害、碰撞、精度和外挂规则，接敌前会冲刺，低血量时可能下蹲，面对没有四肢的对手会改打可见躯干或头部。反应延迟与误差可配表。当前不会主动规划射地飞行、趴下或探头战术，第三人称对机器人的观察逻辑没有额外加成。

## 姿态、动作与个人设置

站立、下蹲、趴下分别使用独立的身体盒、碰撞体和视点；低障碍下禁止站起。走跑摆腿、摆臂、跳跃收腿、爬行和换弹手臂动作共用身体姿态数据，渲染与命中同步。另有受击变色、死亡倒下、武器换弹动作和进度条。

普通走路速度 5.2 米/秒，普通 Shift 冲刺 ×1.5；移速外挂仅在 Shift 冲刺时替换为 ×2.5。下蹲速度 ×0.55，趴下 ×0.25。地面起步与停止采用短加减速，空中有独立控制加速度。地图尺寸、路线和掩体本轮保持不变。

双方血条常驻 HUD，命中提示区分四肢、躯干和头部伤害，受击有红边及方向提示。脚步和落地声包含自己的声音与对手的距离、方位变化；单局和整场有不同的胜负结算与声音。

首页及暂停菜单提供醒目的个人设置入口：鼠标灵敏度、肩射灵敏度倍率、FOV、总音量、整体脚步音量、镜头晃动强度、特效强度，以及键盘和鼠标改键。支持冲突检测、ESC 取消、单项及全部重置。首页有键位介绍，HUD 显示实际绑定。自己的脚步使用较低沉音色，敌方更清脆且有距离与左右方位；不提供单独关闭自己脚步的设置，只有整体音量控制和游戏内“没有脚步”外挂。设置仅保存于自己的浏览器，不修改鼠标硬件 DPI 或公共对局数值；浏览器禁止存储时只在本次页面有效。

普通人机不提供修改外挂入口；首页“练习 / 外挂调试”是单独的练习入口，进入后可在暂停菜单自由切换自己外挂。真人模式没有调参入口。Excel 和本文只存本地，不包含在网站静态资源中。

400 生命下，不计散布和回血，四肢需要 8 发命中，理想击杀间隔约 0.81 秒；躯干需要 16 发，约 1.73 秒；头部需要 40 发，超过一个弹匣。保持射速和伤害用于本轮 TTK 对照测试。

## 肩射、位移与表现

按住右键进入肩射，视野为个人 FOV × 0.88，当前姿态散布 × 0.65，姿态移速 × 0.75；禁用 Shift 疾跑，起跳速度 × 0.85，空中控制加速度 × 0.7。不瞬间刹停已有空中速度，不削弱射地升力，伤害和射速不变。第一人称抬枪，第三人称拉近右肩摄像机，灵敏度倍率可单独设置。

V 冲刺距离 4 米，持续 0.2 秒，冷却 10 秒，一次充能。WASD 方向相对水平视角，斜向归一化，相反输入抵消，无方向则向前。地面与空中均可用，保留竖直速度与重力，碰墙终止，没有无敌或穿墙效果；移速外挂不叠加，落地不刷新冷却。期间禁射且退出肩射，持续按右键在结束后恢复肩射；换弹计时不中断。蹲趴先检查能否站起，头顶阻挡时不能发动且不消耗冷却。HUD 显示冷却，每回合重置。

角色采用轻量程序化人形：头盔、面罩、胸甲、分段手臂和腿、关节、手与靴子，配双手持枪、走跑、起跳、蹲趴、换弹、受击和倒地动作。渲染与命中使用共享部位姿态。第一人称有手和枪，第三人称显示枪并跟随俯仰。枪口闪光、弹道、落点碎屑、射地及位移粒子、单局和整场不同庆祝效果可通过特效强度减少。

## 配表使用

1. 用 Excel 或 WPS 打开 config/游戏数值.xlsx，只修改“数值配置”D 列黄色 value 数值；不要改 key、表头或删除行，不接受公式。
2. 保存并关闭表格，双击根目录“应用配表.cmd”。它先校验所有字段，再更新 config/balance.csv，并启动本地游戏。失败时保留旧 CSV。
3. 打开 http://127.0.0.1:5189 。如已有旧服务，请先关闭旧服务再运行。无需改游戏源代码。
4. 手动流程：npm run import-balance，再 npm run dev。熟悉 CSV 时也可直接改 balance.csv，但下次应用 Excel 会覆盖 CSV，应保持主表同步。
5. 本地改表不会自动更新线上网站；确认手感后重新构建发布。双方游玩同一发布版本，真人对局由房主统一模拟。
6. 需要扩展玩法逻辑（新增外挂、枪械、地图、技能）时仍需开发；配表只负责已有数值。

## 联机和验证边界

房间信令由 Worker + D1 保存，房间码十分钟过期；建立连接后过期不影响对局。房主浏览器运行权威模拟，WebRTC 同步；当前使用 STUN，没有 TURN 中继、主机迁移、断线重连、延迟补偿或访客预测。严格 NAT 可能连接失败，跨地区网络可能手感不佳。完整实机跨网络验收尚未完成。

## 文件与磁盘约定

源码、文档、Excel、CSV、node_modules、缓存、截图、构建包均保留于 F 盘本项目。项目 npm 缓存为 .cache/npm，项目临时目录为 .cache/tmp。Codex 与浏览器已安装的共享运行时属于系统工具，不搬移或复制。此约定写入 AGENTS.md 供后续开发遵守。
