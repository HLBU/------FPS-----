# 史上最反人类 FPS：机制与数值说明

本文由实际配表生成，修改 config/balance.csv 后重新构建会同步更新。Excel 主表为 config/游戏数值.xlsx，日常调整建议从 Excel 主表开始。

## 定位和当前范围

电脑浏览器键鼠、3D、小型竞技地图、真人 1V1 与单人人机。核心是部位伤害倒置、官方外挂与违反传统操作习惯的移动射击。双方采用同一把全自动步枪。包含右键肩射和 V 短冲刺。尚未加入瞄准镜、护甲、多人队伍、经济系统和其他枪械。

## 对局流程

1. 人机模式直接开局；真人模式由一人创建房间，复制邀请链接，另一人打开链接并点击加入。
2. 网站已经开放链接访问，访客无需 ChatGPT 账号。房间码独立于网站访问权限。
3. 每回合从十个外挂中分别独立随机提供三个；双方只收到自己的候选，各暗选两个不同的外挂；双方可以选中相同外挂。双方确认后进入 5 秒准备阶段，公开双方外挂与说明，禁止移动、跳跃和开火，倒计时结束后统一开战。
4. 外挂持续有效，没有周期触发；所有玩家另有一个带冷却的公共位移技能。每小局结束、开始下局时全部清空。
5. 先赢 3 小局获胜，通常最多 5 个有胜负的小局。平局重赛不计胜负。
6. 每小局 75 秒，一人生命归零即结束。没有末段强制公开；超时比较剩余生命，同血量重赛。

7. 同一模拟步按玩家顺序处理，先触发击杀即结束本局，不额外结算双方同时死亡。
8. 小局结束后点击进入下一局；平局沿用该局号重赛。整场结束可点击“再来一场”。服务器联机需双方点击准备，人机由玩家点击继续。

## 操作

| 输入 | 功能 |
|---|---|
| WASD | 移动；斜向归一化，不会更快 |
| 鼠标滑动 | 直接转向，无需按住右键 |
| 左键 | 按住持续射击 |
| 右键 | 按住肩射：略微放大、减小散布并限制机动性 |
| 空格 | 跳跃；按住落地后连续跳跃。趴下时首次按下只尝试站起，松开后再按才跳 |
| Q / E | 按住向左 / 右探头；同时按下中和，松开回正 |
| R | 手动换弹／再次按下取消；空匣自动换弹 |
| Shift | 按住冲刺；仅站立姿态可冲刺且仍可射击 |
| Ctrl | 按住下蹲，松开尝试站起；上方受阻时保持蹲姿 |
| Z | 切换趴下和站立；上方受阻时不能站起 |
| V | 短距离水平冲刺：方向由 WASD 决定，无方向输入则向前；空中可用 |
| ESC | 暂停菜单并释放鼠标 |

默认使用浏览器鼠标锁定，支持无限转向。在不允许鼠标锁定的内置网页中，可用“窗口内自由视角”，同样直接滑动鼠标转向，但光标到窗口边缘时受限，推荐在独立 Chrome / Edge 中玩。方向键保留作为备用转向。人机暂停会停止模拟；真人对局菜单不会暂停另一名玩家。

## 基础战斗

- 全自动即时命中射击，最大射程 100 米，不使用飞行中的实体弹丸。
- 最大生命 400；头部 10、躯干 25、四肢 50 单发伤害，没有距离衰减。
- 站立散布最大，实际水平速度超过 1 米/秒时采用移动散布；不接地时采用腾空散布。散布数值是水平和俯仰各自的最大随机偏角，单位弧度。
- 子弹间隔 0.125 秒，约 480.0 发/分钟；30 发弹匣。无限子弹不消耗弹药。
- 空匣自动换弹，也可按 R；有弹时仅按 R 手动换弹。时间 = min(1.975, 0.75 + 2.45 × min(剩余弹量, 弹匣一半) / 30) 秒。当前空匣 0.75 秒、半匣及以上 1.975 秒。再次按 R 或发动 V 取消；有剩余子弹时重新按左键可取消并开火。取消空匣自动换弹后，需再按 R 或松开后重新按左键，不会反复自动重启。取消不补弹，下次从头换；走跑蹲趴和跳跃不打断。开始、插弹匣及完成有独立声音，完成有闪亮弹量和提示。
- 向下开枪时立即保证至少 9 米/秒升速，后续射击增量为向下方向分量 × 6，向上速度封顶 14 米/秒，脚底最高 8 米。空中射击命中敌人时不增加本发向上升力，已有上升速度保留；打空和射地仍可起飞。水平反推和朝上射击向下反推当前未启用。不会造成自伤。
- 自瞄仅锁定前方半角 1.15 弧度内直接可见的四肢。无四肢时完全失效；锁定成功时不受普通散布影响。鼠标停动 90ms 后镜头缓慢跟踪，鼠标输入立即优先。低头超过约63度仍优先保留射地操作。
- 镜头先寻找准星下的敌人或场景点，再由受墙体限制的枪口发射射线；枪口受阻时不能凭第三人称镜头绕墙命中。

## 探头的真实判定

Q 为左、E 为右。头部最大侧移 0.48 米，躯干和手臂分别使用0.52、0.5权重，腿不侧移。镜头最大倾斜 10 度，以 6/秒限速接近输入；眼睛、枪口和受击部位同步变化。贴墙检查上半身部位体积，并在探头后移动时检查碰撞，受阻收缩。

## 十个官方外挂

| 外挂 | 当前规则 |
|---|---|
| 透视 | 持续显示敌人位置和墙后轮廓，但目标有“没有脚步”时屏蔽；正常视线不受影响 |
| 自瞄 | 前方范围内锁可见四肢；无四肢完全反制，锁定无普通散布；不隔墙锁定 |
| 子弹穿墙 | 内部墙体和掩体可穿，外围边界不可穿，保持完整伤害，不附赠透视或隔墙锁定 |
| 没有脚步 | 取消自己的移动和落地声音，同时屏蔽敌方透视轮廓；枪声、正常视线与自瞄不被屏蔽 |
| 第三人称 | 右肩后置摄像机，肩射时拉近，碰墙时收回；准星视线向目标点收敛，从受障碍限制的角色枪口判定遮挡，不能用摄像机绕墙开枪 |
| 超级移速 | 不按 Shift 与普通玩家同速；按住 Shift 达基础速度 × 2.5（13 米/秒），不再叠乘普通冲刺 |
| 没有四肢 | 四肢不可见且不参与命中，头和躯干仍可受伤 |
| 无限子弹 | 弹匣不消耗，无需换弹，射速不变 |
| 自动回血 | 持续 50 点/秒，受击不中断，最多恢复到 400；死亡后不复活 |
| 人物缩小 | 模型、命中区域、移动碰撞和视点同步变为 70%，基础移速不变 |

## 地图与人机

地图为 32×40 米镜像训练场：中央核心障碍、两条侧翼、交叉连接、低掩体和底部露腿隔断。墙体阻挡移动、视线和自瞄，但不阻挡穿墙外挂。角色有水平边界限制，不可飞出地图。没有可破坏建筑或多层复杂室内空间。

机器人使用网格寻路，直接可见时追击射击，丢失视线时追踪最后位置；没有透视时不会无条件知道墙后坐标。它使用相同血量、伤害、碰撞、精度和外挂规则，接敌前会冲刺，接敌时可能下蹲，面对没有四肢的对手会改打可见躯干或头部。反应延迟 0.35 秒、跟踪间隔 0.14 秒、误差 0.07 弧度可配表；10米内移动且非静音的目标可以被听见，静音同时克制人机透视。采用间歇射击与最后位置搜索。当前不会主动规划射地飞行、趴下或探头战术，第三人称对机器人的观察逻辑没有额外加成。

## 姿态、动作与个人设置

站立、下蹲、趴下分别使用独立的身体盒、碰撞体和视点；低障碍下禁止站起。姿态切换在 0.18 秒内同步平滑过渡视点、模型部位及命中区域，移动碰撞使用起止姿态保守包络，过渡未完成时不能提前钻入低缝。走跑摆腿、摆臂、跳跃收腿、爬行和换弹手臂动作共用身体姿态数据，渲染与命中同步。另有受击变色、死亡倒下、武器换弹动作和进度条。

普通走路速度 5.2 米/秒，普通 Shift 冲刺 ×1.5；移速外挂仅在 Shift 冲刺时替换为 ×2.5。下蹲速度 ×0.6，趴下 ×0.25。地面起步与停止采用短加减速，空中有独立控制加速度。地图尺寸为32×40米，采用固定路线与掩体。

双方血条常驻 HUD，命中提示区分四肢、躯干和头部伤害，受击有红边及方向提示。脚步和落地声包含自己的声音与对手的距离、方位变化；单局和整场有不同的胜负结算与声音。

首页及暂停菜单提供醒目的个人设置入口：鼠标灵敏度、肩射灵敏度倍率、FOV、总音量、整体脚步音量、镜头晃动强度、特效强度，以及枪声／命中音量、界面音量、低中高画质、性能信息、位移动效开关、键盘和鼠标改键。敌方脚步使用HRTF空间方位，保留距离衰减与敌我音色区别；脚步噪声缓冲复用，退出对局停止活动音源。低画质关闭阴影并降低像素比，中高画质采用不同阴影分辨率；角色几何体复用。支持冲突检测、ESC 取消、单项及全部重置。首页有键位介绍，HUD 显示实际绑定。自己的脚步使用较低沉音色，敌方更清脆且有距离与左右方位；不提供单独关闭自己脚步的设置，只有整体音量控制和游戏内“没有脚步”外挂。设置仅保存于自己的浏览器，不修改鼠标硬件 DPI 或公共对局数值；浏览器禁止存储时只在本次页面有效。

普通人机不提供修改外挂入口；首页“练习 / 外挂调试”是单独的练习入口，进入后可在暂停菜单自由切换自己外挂。真人模式没有调参入口。Excel 和本文只存本地，不包含在网站静态资源中。

400 生命下，不计散布和回血，四肢需要 8 发命中，按配置理想击杀间隔约 0.875 秒；躯干需要 16 发，约 1.875 秒；头部需要 40 发，超过一个弹匣。射击冷却保留时间余量，固定步长模拟在30／60／120 Hz持续10秒均发射80发，即480 RPM。单发时刻仍量化到模拟步长，但误差不逐发累积。人机遇短暂慢帧会补足模拟步，单次长卡顿最多追赶0.5秒以防无限追赶。

## 肩射、位移与表现

按住右键进入肩射，视野按光学放大 1.15 倍换算：FOV肩射 = 2×atan(tan(FOV个人/2)/1.15)，默认78°约70.3°，当前姿态散布 × 0.65，姿态移速 × 0.75；禁用 Shift 疾跑，起跳速度 × 0.85，空中控制加速度 × 0.7。不瞬间刹停已有空中速度，不削弱射地升力，伤害和射速不变。第一人称抬枪，第三人称拉近右肩摄像机，灵敏度倍率可单独设置。

V按下即播放本地风切声、速度线和镜头反馈，服务器用位移序号确认并去重；被拒绝时结束反馈，位置以权威快照纠正。视听预反馈不代表提前确认命中或无敌。V 冲刺采用匀速曲线；总距离与帧率无关。带风切声、方向速度线、短暂残影拖尾、小幅视野扩张和武器后压，正常结束与撞墙有不同声光反馈。特效强度可调，减少动态效果时关闭速度线及镜头响应。V 冲刺距离 5 米，持续 0.2 秒，冷却 5 秒，一次充能。WASD 方向相对水平视角，斜向归一化，相反输入抵消，无方向则向前。地面与空中均可用，保留竖直速度与重力，碰墙终止，没有无敌或穿墙效果；移速外挂不叠加，落地不刷新冷却。期间允许射击并使用移动精度（空中仍使用腾空精度），退出肩射，持续按右键在结束后恢复肩射；发动时打断换弹。蹲下和趴下均保持原姿态发动，不强制站起，碰撞与命中仍使用对应姿态。HUD 显示冷却，每回合重置。

角色采用轻量程序化人形：头盔、面罩、胸甲、分段手臂和腿、关节、手与靴子，配双手持枪、走跑、起跳、蹲趴、换弹、受击和倒地动作。渲染与命中使用共享部位姿态。第一人称有手和枪，第三人称显示枪并跟随俯仰，补充附枪双手及换弹偏转。没有四肢时对应手部也隐藏。保留程序化模型，未引入外部模型或新引擎；完整骨骼IK、资源美术替换仍待后续打磨。枪口闪光、弹道、落点碎屑、射地及位移粒子、单局和整场不同庆祝效果可通过特效强度减少。

## 规则之间的关系

| 组合 | 判定 |
|---|---|
| 透视对没有脚步 | 不显示透视轮廓；正常视线仍可看见 |
| 自瞄对没有四肢 | 没有合法锁定部位，自瞄失效 |
| 自瞄加穿墙 | 不能隔墙自动锁定；可手动朝墙后目标射击 |
| 无限子弹加射地起飞 | 不因弹匣耗尽停止，可持续增加升力但仍受高度及速度上限限制 |
| 肩射加位移 | 位移期间退出肩射，持续按右键则结束后恢复 |
| 移速外挂加位移 | 不增加位移距离，普通疾跑与外挂倍率不叠乘 |
| 缩小加探头／姿态 | 视点、模型、碰撞及命中区域一起缩放 |

## 换弹细则

非空弹匣只由手动换弹启动；射完最后一发自动换弹。剩余弹量越多换弹越慢，超过半匣不再继续变慢。

换弹时间 = min(上限时间，空匣时间 + 额外时间 × min(剩余弹量，半匣容量) / 弹匣容量)。

重新按R、发动V位移可打断；仍有子弹时重新按下射击也可打断并开火。单纯保持射击键不会反复打断。走跑、蹲趴和跳跃不中断。取消不补充子弹，重新启动需要完整时间。空匣换弹取消后不会马上再次自动启动，需重新按R或松开再按射击。开始、中段、完成与取消具有声音提示，完成时弹药显示闪动。

## 射击与升力判定

先从摄像机准星获取目标点，再从受墙体限制的枪口向目标点发射；普通散布在此基础上生效，自瞄成功锁定时不加普通散布。每发只结算最先命中的一个部位。命中体积采用当前姿态及动作。场地墙体不减穿墙伤害，外围边界仍阻挡子弹。

向下射击分量超过0.25时可以起飞：新向上速度取最大上升速度与“起飞保底速度、原向上速度加朝下分量×单发升力两者中的较大值”中较小者。空中命中敌人则不增加本发升力。没有水平反推、朝上射击向下反推或坠落伤害。

## 配表使用

1. 用 Excel 或 WPS 打开 config/游戏数值.xlsx，只修改“数值配置”D 列黄色 value 数值；不要改 key、表头或删除行，不接受公式。
2. 保存并关闭表格，双击根目录“应用配表.cmd”。它先校验所有字段，再更新 config/balance.csv，并启动本地游戏。失败时保留旧 CSV。
3. 打开 http://127.0.0.1:5189 。如已有旧服务，请先关闭旧服务再运行。无需改游戏源代码。
4. 手动流程：npm run import-balance，再 npm run dev。熟悉 CSV 时也可直接改 balance.csv，但下次应用 Excel 会覆盖 CSV，应保持主表同步。
5. 本地改表不会自动更新线上网站；确认手感后重新构建发布。本地和Node服务器入口采用同一份共享规则，由服务器统一模拟；旧Worker入口保留原有WebRTC兼容路径。线上版本须经明确发布后才会更新。
6. 需要扩展玩法逻辑（新增外挂、枪械、地图、技能）时仍需开发；配表只负责已有数值。

## 联机和验证边界

本地 npm run dev 和Node服务入口使用WebSocket服务器权威模拟，60 Hz判定、20 Hz状态快照；每人只收到自己的候选池，选卡期间对方候选与所选外挂均不发送。双方浏览器只发送输入，不能自行修改血量、命中或比赛结果。自己的移动采用预测、确认后重放未确认输入和轻微误差平滑；对手以100ms缓冲插值，不无限外推。服务器按测得往返延迟约束命中回溯，最多 150ms，不跨小局回溯。模拟输入队列、速率及发送积压有界；不接收客户端伪造的世界快照。下一小局和再来一场均等双方点击准备。未加入好友或账号系统。房间等待十分钟过期，离开任一端关闭房间；没有断线重连或房主迁移。浏览器不再承担本地联机裁判，服务器后台运行不受房主页面限速影响。旧Worker/Sites入口保留WebRTC兼容路径，仍有STUN/NAT及房主权限限制；迁移生产网络入口需单独发布和验收。阿里云测试入口已采用该服务器判定路径；旧Sites入口独立维护。跨网络、高延迟、丢包和真实设备对战仍需验收。
