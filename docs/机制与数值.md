# 史上最反人类 FPS：机制与数值说明

本文由实际配表生成，修改 config/balance.csv 后重新构建会同步更新。Excel 主表为 config/游戏数值.xlsx，日常调整建议从 Excel 主表开始。

## 定位和当前范围

电脑浏览器键鼠、3D、小型竞技地图、真人 1V1 与单人人机。核心是部位伤害倒置、官方外挂与违反传统操作习惯的移动射击。双方采用同一把全自动步枪。尚未加入开镜、护甲、多人队伍、经济系统和其他枪械。

## 对局流程

1. 人机模式直接开局；真人模式由一人创建房间，复制邀请链接，另一人打开链接并点击加入。
2. 网站已经开放链接访问，访客无需 ChatGPT 账号。房间码独立于网站访问权限。
3. 每回合从十个外挂中随机提供同样的三个；双方各暗选两个，允许选重，双方确认后公开。
4. 外挂持续有效，没有周期触发或主动技能冷却。每小局结束、开始下局时全部清空。
5. 先赢 3 小局获胜，通常最多 5 个有胜负的小局。平局重赛不计胜负。
6. 每小局 75 秒，一人生命归零即结束。最后 15 秒双方轮廓公开；超时比较剩余生命，同血量重赛。

## 操作

| 输入 | 功能 |
|---|---|
| WASD | 移动；斜向归一化，不会更快 |
| 鼠标滑动 | 直接转向，无需按住右键 |
| 左键 | 按住持续射击 |
| 右键 | 保留给后续开镜，当前无游戏功能 |
| 空格 | 跳跃；按住落地后连续跳跃 |
| Q / E | 按住向左 / 右探头；同时按下中和，松开回正 |
| R | 换弹 |
| ESC | 暂停菜单并释放鼠标 |

默认使用浏览器鼠标锁定，支持无限转向。在不允许鼠标锁定的内置网页中，可用“窗口内自由视角”，同样直接滑动鼠标转向，但光标到窗口边缘时受限，推荐在独立 Chrome / Edge 中玩。方向键保留作为备用转向。人机暂停会停止模拟；真人对局菜单不会暂停另一名玩家。

## 基础战斗

- 全自动即时命中射击，最大射程 100 米，不使用飞行中的实体弹丸。
- 最大生命 100；头部 10、躯干 25、四肢 50 单发伤害，没有距离衰减。
- 站立散布最大，实际水平速度超过 1 米/秒时采用移动散布；不接地时采用腾空散布。散布数值是水平和俯仰各自的最大随机偏角，单位弧度。
- 子弹间隔 0.115 秒，约 521.7 发/分钟；24 发弹匣。无限子弹不消耗弹药。
- 空匣按 R 需 0.65 秒，非空匣按 R 需 1.75 秒；不会自动换弹。
- 每次朝下开枪给予向上速度增量，增量为向下方向分量 × 3.3，向上速度封顶 8.5 米/秒，脚底最高 8 米。不会造成自伤。
- 自瞄在开火时工作，必须有直接视线，优先可见四肢，然后躯干和头。向下俯视超过约 63° 时优先保留射地操作，避免锁定阻碍起飞。

## 探头的真实判定

Q 为左、E 为右。围绕距离脚底 0.7 米的髋部支点倾斜上半身，最大 0.35 弧度（约 20.1°）。头、躯干、手臂与武器外观随之移动，腿保持原位。眼睛与射击起点跟随探头；敌人命中判定使用同样变换后的部位盒。探头接近墙体时会收缩，避免视点穿墙。第一人称有小幅画面倾斜，第三人称仍能探头。

## 十个官方外挂

| 外挂 | 当前规则 |
|---|---|
| 透视 | 持续显示敌人位置和墙后轮廓，显示其实际探头及缩小姿态 |
| 自瞄 | 开火时锁可见要害，手动开火，仍受散布影响；不能隔墙锁定 |
| 子弹穿墙 | 所有场景墙体均可穿，保持完整伤害，不附赠透视或隔墙锁定 |
| 没有脚步 | 取消移动脚步声；枪声保留。当前没有独立落地音效 |
| 第三人称 | 后置摄像机，碰墙时收回；弹道仍从角色眼睛发出 |
| 超级移速 | 基础速度 × 2.5，当前 13 米/秒 |
| 没有四肢 | 四肢不可见且不参与命中，头和躯干仍可受伤 |
| 无限子弹 | 弹匣不消耗，无需换弹，射速不变 |
| 自动回血 | 持续 20 点/秒，受击不中断，最多恢复到 100；死亡后不复活 |
| 人物缩小 | 模型、命中区域、移动碰撞和视点同步变为 70%，基础移速不变 |

## 地图与人机

地图为 32×40 米镜像训练场：中央核心障碍、两条侧翼、交叉连接、低掩体和底部露腿隔断。墙体阻挡移动、视线和自瞄，但不阻挡穿墙外挂。角色有水平边界限制，不可飞出地图。没有可破坏建筑或多层复杂室内空间。

机器人使用网格寻路，直接可见时追击射击，丢失视线时追踪最后位置；没有透视时不会无条件知道墙后坐标。它使用相同血量、伤害、碰撞、精度和外挂规则。反应延迟与误差可配表。当前不会主动规划射地飞行或探头战术，第三人称对机器人的观察逻辑没有额外加成。

## 配表使用

1. 用 Excel 或 WPS 打开 config/游戏数值.xlsx，只修改“数值配置”D 列黄色 value 数值；不要改 key、表头或删除行，不接受公式。
2. 保存并关闭表格，双击根目录“应用配表.cmd”。它先校验所有字段，再更新 config/balance.csv，并启动本地游戏。失败时保留旧 CSV。
3. 打开 http://127.0.0.1:5189 。如已有旧服务，请先关闭旧服务再运行。无需改游戏源代码。
4. 手动流程：npm run import-balance，再 npm run dev。熟悉 CSV 时也可直接改 balance.csv，但下次应用 Excel 会覆盖 CSV，应保持主表同步。
5. 本地改表不会自动更新线上网站；确认手感后重新构建发布。双方游玩同一发布版本，真人对局由房主统一模拟。
6. 需要扩展玩法逻辑（新增外挂、枪械、地图、技能）时仍需开发；配表只负责已有数值。

## 联机和验证边界

房间信令由 Worker + D1 保存，房间码十分钟过期；建立连接后过期不影响对局。房主浏览器运行权威模拟，WebRTC 同步；当前使用 STUN，没有 TURN 中继、主机迁移、断线重连、延迟补偿或访客预测。严格 NAT 可能连接失败，跨地区网络可能手感不佳。完整实机跨网络验收尚未完成。

## 文件与磁盘约定

源码、文档、Excel、CSV、node_modules、缓存、截图、构建包均保留于 F 盘本项目。项目 npm 缓存为 .cache/npm，项目临时目录为 .cache/tmp。Codex 与浏览器已安装的共享运行时属于系统工具，不搬移或复制。此约定写入 AGENTS.md 供后续开发遵守。
