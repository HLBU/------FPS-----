## 回退操作说明

以下仅为后续获得明确回退指令后执行的步骤，本轮没有执行。回退将重启本游戏服务，当前内存房间会清空。

1. 检查归档：进入上述服务器目录，运行sha256sum -c SHA256SUMS。
2. 备份届时正在使用的inverse-fps-2.service，保留再次前进的路径。
3. 使用sudo install -m 644将归档rollback.service安装为/etc/systemd/system/inverse-fps-2.service。
4. 运行sudo systemctl daemon-reload及sudo systemctl restart inverse-fps-2.service。
5. 检查systemctl is-active、公开入口、正确/错误测试码、资源加载与双客户端选卡/准备/战斗。

rollback.service直接指向归档server.cjs，不依赖原release目录继续存在。正常代码回退继续使用现有shared/game.env和Nginx路由；不自动覆盖密钥或其他项目Nginx配置。只有环境配置本身损坏时，才另行按明确指令恢复服务器私有配置。
