# 史上最反人类 FPS · 肢体实验室

当前代码包含镜像地图灰盒升级、全图程序化面板材质、图形化战斗反馈及大厅/选卡/亮牌/结算UI。战斗状态主要使用图形和声音，详细规则在选卡中展开；选卡与整场结算复用角色装备预览。68项自动测试通过，主观体验仍待用户集中验收。部署记录与白盒回退说明见docs目录。

浏览器 3D 1V1 可玩原型。Three.js 渲染，共用规则模拟，本地及Node服务使用WebSocket服务器权威对局；Worker入口保留WebRTC兼容路径。单人人机完全在浏览器中运行。

## 本地启动

需要 Node.js 22 或更新版本。

```sh
npm install
npm run dev
```

打开 http://127.0.0.1:5189 。默认不占用其他项目常见的 5173 端口。`PORT` 环境变量可覆盖端口。服务器监听本机所有 IPv4 接口；本地房间信息存内存，服务重启即清空。

Chrome / Edge 电脑键鼠优先。WASD 移动，空格按住连跳，鼠标转向、左键开火，Q/E 按住探头，Shift 冲刺，Ctrl 按住下蹲，Z 切换趴下，R 手动换弹，ESC 暂停/释放鼠标。内置预览不允许鼠标锁定时，使用“窗口内自由视角”：直接滑动鼠标转向或方向键转向；右键保留，左键开火。人机暂停停止模拟；真人对战暂停菜单不停止对局。

## 已实现范围

- 五局三胜。75 秒一回合，没有末段强制公开，超时比较剩余生命；同血量重赛。
- 每回合双方独立随机三个外挂，只收到自己的候选，各选两个；双方确认后公开并准备 5 秒，进入下一轮时清空。
- 一张 32×40 米镜像训练场，两条侧翼、中央连接、低掩体与露腿隔断。墙阻挡移动和视线，穿墙外挂可穿内部墙及掩体且不减伤，外围边界不可穿透。
- 一把全自动步枪，400 生命，30 发弹匣；头 10、躯干 25、四肢 50 伤害。
- 站立散布最大、移动更准、腾空最准；按住空格连续跳；向下射击持续给予升力，高度上限 8 米。
- 空匣自动换弹 0.75 秒；非空匣按 R。剩余子弹越多越慢，半匣及以上封顶 1.975 秒；R／V 可取消，有弹时重新开火可取消。
- 十个持续外挂：透视、自瞄、穿墙、无脚步、第三人称、Shift 冲刺时 2.5 倍移速、无四肢、无限子弹、每秒回血 50 点、缩小至 70%。静音同时屏蔽敌方透视轮廓。
- 自瞄只锁前方可见四肢；锁定无普通散布，无四肢完全反制；鼠标停动 90ms 后缓慢跟镜头，大幅低头优先射地。
- 基础机器人：网格寻路、视线判断、最后位置追踪、反应延迟与瞄准误差。同样遵循伤害、碰撞、弹药和外挂规则。
- 首页“练习 / 外挂调试”入口提供单人暂停菜单修改外挂；普通人机与真人不提供。
- 设置菜单可调整灵敏度、FOV、音量、脚步音量和镜头晃动，保存于当前浏览器。
- 常驻双方血条、受击方向、明显的命中与胜负反馈；共用姿态驱动蹲趴、走跑和命中区域。

## 真人连接

房主点击“邀请朋友 1V1”，等待生成 6 位码，发送邀请链接；另一人加入后双方选卡。代码在同一浏览器的两张标签页也可使用，但后台标签页可能限速，实际体验应使用两台电脑。

本地由服务器每秒60步统一判定，双方发送输入。客户端预测自己的移动、平滑校正位置，并以100ms缓冲显示对手；命中回溯最多150ms，由服务器测得延迟约束。候选池按玩家隔离，选卡期间互不可见。下一局或再来一场需双方点击准备。离开会关闭房间，暂无重连。跨网络实战和恶劣网络仍需人工验收。

本地 npm run dev 已接入新的服务器判定。Node部署入口代码也已准备，但本轮没有部署。现有线上版本保持原状。旧Worker入口保留原WebRTC路径；其网络结构不能仅靠发布静态文件自动切换为Node房间服务。

## 构建与验证

```sh
npm test
npm run build
```

`dist/server/index.js` 是包含静态资源的 Worker ESM。规则在 `src/game.js`，场景与界面在 `src/main.js`，WebRTC 在 `src/network.js`，信令在 `src/signaling.js`。改代码后重启 `npm run dev` 重新构建。数值由 `config/游戏数值.xlsx` → `config/balance.csv` → 共享 CFG 驱动。只改 Excel 的 D 列，保存后双击 `应用配表.cmd` 即可本地试用，线上需重新发布。完整规则见 [机制与数值](docs/机制与数值.md)。

项目缓存与临时文件放在 F 盘仓库 `.cache` 内；此约定已写入 AGENTS.md。

不依赖远程 3D 素材、商业模型或音频文件；模型程序生成，音效使用 Web Audio 合成。字体可在线加载，失败时使用系统字体。


本轮新增：50 HP/s 回血、右键肩射、V 八方向空中冲刺、快速射地起飞、自由空中视角、低模人形和持枪表现、战斗及胜利特效、改键和大厅键位说明。地图保持不变。数值主表新增肩射与冲刺字段。自己的脚步不能单独关闭。

当前本地规则：各自独立三选二且只发送自己的候选；400 HP；30 发；间隔0.125秒；75秒战斗与5秒准备；没有末段公开。自瞄仅锁前方可见四肢且锁定无散布，静音反透视，无四肢反自瞄。位移5米/0.2秒/5秒冷却，蹲趴保持姿态且允许射击。采用镜头选点、枪口发射和枪口遮挡检查。人机反应0.35秒、跟踪间隔0.14秒、误差0.07弧度。本轮加入射击计时余量、0.18秒姿态过渡、1.15倍光学肩射、本地位移预反馈去重、服务器判定与预测插值、有限命中回溯、分组音量／画质／性能设置及双手持枪表现。保留当前轻量工程和地图。
